# 市バスかんたん時刻表 — 設計

## 技術スタック
- フロントエンド: Next.js 15 (App Router) + TypeScript + Mantine
- バックエンド: Next.js Route Handlers / Server Actions
- ORM: Drizzle ORM
- DB: Turso (SQLite/libSQL)
- ホスティング: Vercel
- 定期実行: Vercel Cron（更新チェックのみ）

## アーキテクチャ
```
スマホWeb / PWA
  ↓
Next.js App Router
  ↓
Route Handlers / Server Actions
  ↓
Drizzle ORM
  ↓
Turso
```

## 重要設計判断

### 直通検索: 自己結合方式（MVPはroute_stop_pairs不使用）
bus_stop_times に複合インデックスを張った自己結合で直通検索する。
route_stop_pairs はデータ爆発（O(N²)）のため将来の最適化として設計のみ残す。

### ダイヤ判定: 日付ベース解決
「平日/土曜/休日」の手動3区分はUIの見た目。
内部は「対象日付 → active な service_id 集合」に解決（calendar_dates の例外日自動反映）。

### 時刻保存: 秒int正規化
GTFSの "25:30:00" のような24時超え時刻を0時起点の秒数(int)に変換して保存。
終バス判定・「あと何分」計算を安全に行う。

### 取込: ローカルCLIスクリプト方式
重い取込処理はVercelサーバーレスでなくNode CLIスクリプトでTursoに直接書き込む。

## provider 設計
全テーブルに provider_id を持たせる。
MVPでは固定値 "nagoya_city_bus" を使用。
